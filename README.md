# Task 5: Exploratory Data Analysis (EDA) - Titanic Dataset

## Objective
The objective of this project is to explore the Titanic dataset using Python and identify patterns, trends, missing values, outliers, and relationships between variables.

## Dataset
The Titanic dataset contains passenger information, including age, gender, passenger class, ticket fare, family details, and survival status.

## Tools and Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Tasks Performed
1. Loaded and explored the Titanic dataset.
2. Checked dataset information using `info()`, `describe()`, and `value_counts()`.
3. Identified missing values and duplicate records.
4. Created histograms to understand data distributions.
5. Used count plots to analyze passenger survival by gender and class.
6. Created scatterplots to examine relationships between age and ticket fare.
7. Used boxplots to identify potential outliers.
8. Created a correlation heatmap and pairplot to explore relationships between numerical variables.
9. Recorded observations and summarized the findings.

## Key Findings
- More passengers did not survive than survived.
- Female passengers had a higher survival rate than male passengers.
- First-class passengers generally had better survival outcomes than third-class passengers.
- The Age column contains missing values, and the Cabin column has substantial missing information.
- Ticket fares show a right-skewed distribution, with some unusually high values.

## Conclusion
This project demonstrates how Exploratory Data Analysis helps understand a dataset through statistical summaries and visualizations. The analysis revealed patterns in passenger survival, identified missing values, and highlighted potential outliers.
